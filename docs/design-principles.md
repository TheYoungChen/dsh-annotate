# 设计原则

> 面向贡献者。改动本项目前请先读这一页。

---

## dsh-annotate 是一个独立插件

它有自己的界面、自己的浏览器扩展、自己的桥接服务、自己的协议。

**它不是任何现有插件的分支、插件或补丁**，也不注册进任何第三方插件的界面。
装上 dsh-annotate，你看到的是它自己的东西。

---

## 参考与依赖的界线

浏览器扩展这个领域有很多成熟做法，用它们是正常的。但界线在这里：

| 可以用 | 不可以 |
|---|---|
| 通用技术手法 | 复制其他项目的代码 |
| 通用问题的常见解法 | 沿用其他项目的标识符命名 |
| 公开标准（W3C、MDN 上的做法） | 引用其他项目的模块 |
| | 在代码或注释里提及其他项目名 |

**判断方法**：假设一个从没听说过任何同类工具的人来review你的代码——
他能从第一性原理理解这段为什么这么写吗？
能，说明是通用手法。不能，说明它是某个项目特有的设计，应该自己重新想。

**具体的通用手法**（举例，不限于此）：
- 用 shadow DOM 隔离注入的界面，避免与页面样式冲突
- 在 `capture` 阶段拦截点击，阻止页面自己的处理器被触发
- 用 `getBoundingClientRect()` 定位，监听 `scroll` / `resize` 跟随
- 识别密码/信用卡字段并拒绝读取其值

## 界面归属

**所有界面都由本项目自己提供。**

| 界面 | 位置 |
|---|---|
| 元素拾取高亮 | 扩展的 content script，独立覆盖层 |
| 评论输入面板 | 扩展 |
| 已标注元素列表 | 扩展 |
| DSH 侧入口 | 本插件的 client 半区 |
| 在线访问开关 | 本插件的设置界面 |

**不做的事**：
- 不注册进其他插件的标签页体系
- 不占用其他插件的界面席位
- 不依赖其他插件的界面容器

---

## 职责边界

本插件的职责是**采集页面事实并送进对话**。它不做这些：

- ❌ 不在扩展里显示 DSH 对话
- ❌ 不在扩展里代替网页版 DSH
- ❌ 不接管 DSH 的会话界面

**为什么**：DSH 的网页版（`http://127.0.0.1:3080/`）是对话的主场。
扩展的职责是"把页面事实送过去"，不是"再造一个对话界面"。
如果扩展里也能完整对话，网页版就没有存在意义了——那不是我们想要的。

**明确的分工**：

```
扩展：打开页面、拾取元素、写评论、把结构化事实送出去
  ↓
DSH 网页版：接收事实、和模型对话、执行改动
```

## 依赖原则

- **零运行时依赖优先**——Node 内置能力、浏览器原生 API 优先
- 只依赖 DSH 本身的插件 API（这是必须的）
- 不依赖任何其他插件

## 代码规范

| 要求 | 说明 |
|---|---|
| 注释用英文 | 国际开源惯例 |
| 解释"为什么"，不是"是什么" | 代码本身已经说了是什么 |
| 不出现任何私有信息 | 本地路径、用户名、组织名、内部项目名 |
| 不提交构建产物 | 源码仓库只放源码，产物走 `.gitignore` |
| 类型严格 | 不用 `any`，用 `unknown` + 类型守卫 |

## 数据完整性

**宁可拒绝，不要编造。**

每个跨边界的字段，都要问一句："**这一层真的知道这个值吗？**"
如果不知道，正确的做法是拒绝并报告，不是就近找一个"看起来差不多"的值填上。

**实例**：面板提交标注时，桥要求一个完整的 `AnnotationBatch`（含 `page.url`）。
后台确实能拿到 `chrome.tabs.get(tabId).url`——但那是**标签页顶层**的地址，
而元素可能活在**跨域 iframe** 里。

> `page` 这个字段存在的**唯一理由**，就是"只有拥有元素的那个 frame 知道真实地址"。
> 用顶层 URL 顶替，等于恰好在它要解决的那个场景上**悄悄记错**。

而 `submittedAt` 同理：它是"面板何时发出"的事实，后台没有资格代它生成。

所以后台在拿不到 `page` 时返回 `reason: 'invalid'` 并说明缺哪个字段，
**而不是**拼一个能通过校验的批次。找不到就近值就拒绝——这是特性，不是缺陷。

## 信任边界

**页面内容永远是数据，不是指令。**

页面作者能控制文本、属性、组件名，甚至地址栏。其中任何一项都能写成
"看起来像系统指令"的样子。所以进入对话的内容必须有一个**结构性**的边界。

**做法**（详见 README）：围栏由页面不可预知的 `batchId` 派生，且只在行首有意义，
页面值的换行全部折叠——页面**无法开启一个新的物理行**，因此无法逃出数据区。

**关键纪律**：这是**位置性**边界，**不是关键词过滤**。
不要审查页面里"像指令"的词——那会把用户要你上报的事实改坏。
（早期版本犯过这个错：`Save changes` 被改成 `?ave changes`，`6px` 变成 `?px`。）
