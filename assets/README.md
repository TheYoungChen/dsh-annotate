# assets/

Screenshots and recordings referenced by the root `README.md`.

## Needed

| File | What it should show |
|---|---|
| `hero.png` | The main product shot. Conversation on the left, sidebar preview on the right, one element carrying the orange highlight box in the page, and 2 entries listed in the sidebar panel. Roughly 1600×900. |
| `demo.gif` | The full flow in under 10 seconds: press **Mark** → hover to highlight → click an element → type a note → add to the composer. |

Both are referenced from `README.md` and currently render as broken links, which
is why this file exists — it records exactly what to capture so the placeholders
can be filled in without guessing.

## How to capture

1. Start the Web app and open the **标注** tab in the right sidebar.
2. Open a local page in the preview (one with recognisable content reads best).
3. Press **Mark**, hover an element so the highlight and selector readout are
   both visible, then click it.
4. Add a second element with a note so both kinds appear in the list.
5. For `hero.png`, stop there. For `demo.gif`, record the whole sequence.

Keep file sizes reasonable — a `hero.png` under ~400 KB and a `demo.gif` under
~3 MB keep the repository pleasant to clone.
